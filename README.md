# B2Binc

**Business to Business Indian National Commerce**

Public website for corrugated packaging, manufacturing partners, and import/export.

## Live site

After GitHub Pages is enabled, the site will be available at:

`https://YOUR_GITHUB_USERNAME.github.io/b2binc/`

## Local preview

```bash
cd packtrade
python3 -m http.server 8080
```

Open http://localhost:8080

## Structure

- `index.html` — Home (corrugated, partners, capacity, contact)
- `import-export.html` — Export gallery
- `css/` · `js/` · `assets/`
