# B2Binc website

Static HTML, CSS and JavaScript site published with GitHub Pages at [b2binc.in](https://b2binc.in/).

## Pages

- `index.html` — overview and quote form
- `corrugated-boxes.html` — box requirements
- `corrugated-boards.html` — board and sheet enquiries
- `printed-cartons.html` — printed carton enquiries

The sitemap and robots file are maintained at the repository root. Keep `CNAME` set to `b2binc.in` and keep `.nojekyll` so GitHub Pages serves the static files directly.

## Local preview

Open `index.html` in a browser or use a static local server. No build step is required.

## Publishing and SEO

The GitHub Pages source is the root of the `main` branch. In the repository's **Settings → Pages**, enable **Enforce HTTPS** so HTTP requests redirect to the canonical HTTPS site.

The published copy avoids unconfirmed production capacities, factory details, laboratory tests, certifications and customer claims. Add those details only after B2Binc confirms them. Use company-owned or properly licensed photos for real equipment and facility claims; packaging images on the site are examples, not evidence of a specific customer order.

After publishing content changes, submit the homepage and new product URLs for recrawl in Google Search Console. Add a complete public business address or a local-business profile only after confirming the exact details.
